# ClinicQManage

A backend/desktop service designed to streamline patient queue management and operations in medical clinics. The project is currently under active development, with a functional MVP ready for clinic workflow management.

## 🛠 Tech Stack

* **Framework:** .NET / ASP.NET Core
* **ORM:** Entity Framework Core
* **Database:** PostgreSQL / MS SQL Server
* **Integrations:** Hardware readers / Notification services (Telegram / SignalR)

## 🩺 Features (MVP)

* 🎫 **Queue Management:** Real-time generation and tracking of patient queue tickets.
* 👨‍⚕️ **Doctor Cabinet Interface:** Seamless queue processing and status updates by medical staff.
* 🔔 **Live Notifications:** Real-time patient alerts and display updates.
* 📊 **Visit Logging:** Basic analytics and visit history tracking.
